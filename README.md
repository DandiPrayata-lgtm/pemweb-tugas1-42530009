# TRAJA — Katalog Tradisional Jamu Indonesia

Tugas 1 Pemrograman Web (Tema B — Katalog Produk Digital).

## Struktur
- `index.html` — halaman tunggal (Beranda → Produk → Paket → Testimoni → CTA)
- `css/style.css` — CSS Custom Properties, Flexbox, CSS Grid, mobile-first (breakpoint 768px & 1024px)
- `assets/images/` — ilustrasi produk (PNG); `assets/icons/` — logo TRAJA

## Produk
Jamu Temulawak, Jamu Kencur, Jamu Beras Kencur — masing-masing Rp15.000.
Paket bundling: 2 Jamu Rp23.000, 3 Jamu Rp40.000 (bukan langganan bulanan).

## Cara menjalankan
Ekstrak zip, lalu buka `index.html` di browser. Ubah nama folder sesuai ketentuan tugas bila diperlukan.

## Teknologi
HTML5 semantik, CSS3, tanpa framework.
